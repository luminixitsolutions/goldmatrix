2. Shared rules (ledger reports)

  • Primary table: tbl_customer_ledger — customer_name is the ledger name.
  • Party typing: tbl_customers.sundry_debtors_id — commonly 1 = debtor (current assets), 2 = creditor (current liabilities), 29 = bank (current assets).
  • Sign convention: Positive = Debit, negative = Credit (JewelSteps-style).
  • GET parameter: date_range = DD-MM-YYYY - DD-MM-YYYY (space-hyphen-space between dates).
  • Default date behaviour: First visit (no date_range in URL) → current Indian FY (April–March). Empty range + Apply → all dates (opening from transaction_type = 'opening').
  • Opening (when from/to set): Last balance_amount before from_date for that ledger.
  • Period movement: Sum debit_amount / credit_amount where transaction_type ≠ opening, within range.
  • Closing: opening + period_debit − period_credit.
  • Excluded ledger: Purchase Fixing Account filtered out on TB-style reports.

3. Trial Balance

File: trial-balance.php

Shows one row per aggregated group (not each ledger): Opening, Debit, Credit, Balance.

Group order: Current Liabilities → Current Assets → Sales Account → Purchase Account → Indirect Expenses → Profit and Loss → Profit and Loss Opening.

Mapping function groups each customer_name into those buckets (named accounts + party sundry type).

4. Balance Sheet

File: balance-sheet.php — uses fs_compute_ledger_groups() in includes/fs_ledger_groups.php.

  • Current Liabilities (display): −1 × closing of group Current Liabilities.
  • Profit and Loss block: Combines Profit and Loss Opening display and a computed “current” piece from Sales + Purchase + Indirect Expenses + Profit and Loss group closings (each negated for display).
  • Current Assets: Group closing for Current Assets.
  • Closing stock: SUM(value) from tbl_stock where active stock rows exist.
  • Balancing difference: Plug so total assets align with total liabilities (see code in balance-sheet.php).

5. Profit and Loss

File: profit-loss.php — fs_compute_pnl_buckets().

Buckets (sales, purchase, direct/indirect expense/income) use pl_map_ledger_for_pnl(); P&L reserve ledgers are excluded from trading buckets.

Net formulas: e.g. sales net = credits minus debits on sales bucket; purchase net = debits minus credits; similar for other buckets (see fs_ledger_groups.php return block).

Closing stock from tbl_stock; opening stock is 0 in code until posted elsewhere.

Gross profit = (closing stock + sales + direct income) − (opening stock + purchase + direct expenses). Net = gross + indirect income − indirect expenses.

6. Cash Flow

File: cash-flow.php

For each ledger, computes opening/period/closing as usual, then assigns closing balance to a cash-flow bucket (Capital, Loans, Current Assets, Sales, Direct Income, etc.) via cash_flow_map_ledger_to_bucket(). Left and right columns sum those bucket closings.

7. Fund Flow

File: fund-flow.php

Working capital table: Current Assets and Current Liabilities opening/closing and change; working capital = CA − CL. Sources section uses the same P&L net result as Profit Loss (with stock) for net profit/loss line.

8. Chart of Account

File: chart-of-account.php

Same period arithmetic as Trial Balance, but each ledger is placed in a folder path via auragold_coa_ledger_folders() (broader tree: direct income/expense, fixed assets, investments, capital, loans, GST/TDS-style names, etc.).

9. Tax Return

File: tax-return.php

Parameters: tab, start_date, end_date. Main “tax-return” tab aggregates VAT-style figures from sale invoice line data and customer address/state mapping (not from tbl_customer_ledger for that block).

10. Sale Analysis & Purchase Analysis

Files: sale-analysis.php, purchase-financial-analysis.php

Currently use static sample rows in PHP arrays for demonstration; production use requires wiring to invoice/line-item queries.

11. Trial Balance Detailed Report

File: trial-balance-detailed-report.php

Identical grouping and math as Trial Balance, plus child rows listing each ledger (customer_name) under its group.
